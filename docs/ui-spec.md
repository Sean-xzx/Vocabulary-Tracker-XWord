# XWord 界面规范 v2（简约、大气、有层次）

所有数值都以 `src/renderer/src/styles/design.css` 的变量为准；本文件说明“为什么”和“怎么用”。
设计依据是 `design-assets/`（ui/ui-spec-v2.md、四张参考稿 ui-*.html、motion/motion-spec.md），本文件合并了其中的规范。
颜色沿用原方案，v2 的变化集中在“层次”和“留白”。

## 1. 理念

整体气质：安静、克制、有纸感，像一张暖色的纸和一支笔，不要“科技感”。判断一个设计是否合适，看三条：

1. **内容优先**：界面退到后面，工具只在需要时出现。
2. **靠明度分层，不靠边框**：区域之间用上下层的明度差区分；1px 线只用于表格行和控件描边。
3. **拒绝廉价的“AI 感”**：不用渐变光效、不用 emoji 图标、不用弹跳动画、不用大面积饱和色、不用彩色大阴影。

## 2. 四层表面（层次感的来源）

从低到高：**desk 桌面 → paper 纸面 → raised 抬起 → overlay 浮层**。每升一层：颜色更亮一点、阴影更重一级。

| 层   | 变量        | 浅色    | 深色    | 用在哪里                                                     |
| ---- | ----------- | ------- | ------- | ------------------------------------------------------------ |
| 桌面 | `--desk`    | #F3ECE1 | #171513 | 窗口底色；侧栏直接放在桌面上，不画边框；复习中整个窗口是桌面 |
| 纸面 | `--paper`   | #FAF7F2 | #1E1B18 | 主内容区：距窗口上、右、下各 12px，圆角 18，`--shadow-1`     |
| 抬起 | `--raised`  | #FFFDF9 | #27231F | 纸上的卡片、列表、输入框、选中项、复习卡片                   |
| 浮层 | `--overlay` | #FFFDF9 | #2F2A25 | Popover、菜单、Dialog、Toast，`--shadow-3`                   |

- 同一层内部不用边框分区；1px 线只在两处使用：表格的行（`--hair`），控件的描边（`--border`，即设计稿的 --line）。
- 阴影三级：`--shadow-1`（纸面、选中项、按钮）/ `--shadow-2`（复习卡片）/ `--shadow-3`（浮层），都柔和、低不透明度。

## 3. 颜色

| 变量                                           | 浅色                        | 深色                        | 用途                                   |
| ---------------------------------------------- | --------------------------- | --------------------------- | -------------------------------------- |

| `--faint`                                      | #A89C8F                     | #756B61                     | 更淡的文字：序号、日期、占位           |
| `--border` / `--hair` / `--rule-strong`        | #E2D5C2 / #ECE4D7 / #C9BCA6 | #3A342E / #2C2824 / #5E554C | 控件描边 / 表格行线 / 单词页复习栏竖线 |
| `--accent`                                     | #C9814B                     | #D9955F                     | 陶土：每屏唯一的主元素                 |
| `--marker`                                     | #D9B23A                     | #E3BE4E                     | 荧光笔                                 |
| `--tint-due` / `--tint-late` / `--tint-select` | 荧光黄 24% / 42% / 30%      | 20% / 36% / 26%             | 到期 / 拖欠 / 选中的半透明底           |
| `--danger`                                     | #B5483B                     | #E07A6C                     | 只用于叉号和错误提示                   |

克制原则：

- **每屏只有一个陶土色的主元素**（主按钮或“今天”标记）。
- **黄色只用在三个地方**：荧光笔（Logo、进度条、划过）、到期或选中状态的半透明底色、难词星标。
- 不用渐变，不用彩色的大阴影，不用 emoji；留白是有意的，不要为了“填满”加东西。
- 所有颜色都是 CSS 变量。除 design.css、主进程窗口模块里的两个背景色外，一律不写十六进制色值（lint 会查）。

## 4. 字体与排版

- 界面字体：`"Segoe UI", "Microsoft YaHei UI", "Microsoft YaHei", "PingFang SC", sans-serif`；中文一律用界面字体。
- 衬线字体（`Newsreader, Georgia, …`，本机没有 Newsreader 时用 Georgia）只用于英文单词、字标和数字。
- **所有数字（统计、进度、日期）用衬线字体 + tabular-nums**（类名 `.num`）。

| 用途           | 规格                                                       |
| -------------- | ---------------------------------------------------------- |
| 页面标题       | 界面字体 26px / 600，上方一行 13px 次要色小标题（eyebrow） |
| 统计大数字     | 衬线 60px / 500                                            |
| 复习卡片单词   | 衬线 60px / 600，字距 -0.02em                              |
| 词库详情单词   | 衬线 40px / 600                                            |
| 网格单词       | 衬线 18px / 400                                            |
| 正文、词义     | 14.5–15px；网格词义用次要色                                |
| 标签、表头     | 12–13px，次要色                                            |
| 快捷键提示 kbd | 11px，raised 底，1px 描边，圆角 5                          |

## 5. 布局

- 间距阶梯：4 / 8 / 12 / 16 / 24 / 32 / 44；页面内边距：上 32，左右 44。圆角阶梯：5 / 9 / 10 / 14 / 18 / 22。
- **侧栏 232px**：顶部 28px Logo 图形 + 22px 衬线字标；导航项高 38、圆角 10、图标 18；选中项 = 浅色主题 paper 底、深色主题 raised 底，
  外加 `--shadow-1`、字重 600；“今日复习”右侧数量胶囊用 `--tint-select`；底部是“连续打卡”小卡片，下面是设置入口。
- **页面头部**：左边小标题 + 标题 + 一行 meta，右边操作按钮；每屏最多一个主按钮。
- **按钮**：高 36、圆角 9；页面级主操作（例如“开始复习”）高 48、圆角 12，按钮上带快捷键提示。
- 各页面（对照 design-assets/ui 的参考稿）：
  - **单词页**：表格直接画在纸面上，行高 46，行间 `--hair`；词义列与复习栏之间一条 1.5px `--rule-strong` 竖线（呼应 Logo）；
    复习栏每列宽 64，表头两行（节点名 + 衬线日期），今天那一列的表头用陶土色写“今天”；到期格 `--tint-due`、拖欠格 `--tint-late` +
    右上角陶土色小点；输入行用 raised 底；义项面板是 overlay；底部一行图例（今天到期 / 拖欠 / 模糊）。
  - **今日复习概览**：三组衬线大数字（到期复习 / 新词 / 其中拖欠）用细竖线分隔；右侧“预计 N 分钟”和主按钮；
    下方 raised 的复习顺序列表，最后几行逐渐变淡。
  - **复习中**：侧栏收起，整个窗口是桌面；中央卡片 640×400、raised、圆角 22、`--shadow-2`；卡片下方四个评分按钮 138×52，
    选中用 `--tint-select`；底部 56px 状态栏（paper 底 + 顶部 hair 线）：荧光笔进度条、衬线“8 / 28”、跳过、结束；左上角小 Logo。
  - **词库**：页头右侧是搜索框；筛选是胶囊按钮；列表行高 56（单词一行、词义一行），选中行 = raised + `--shadow-1`；
    详情按“词义 / 助记 / 例句 / 复习格 / 复习历史”分区，分区之间只靠留白，不画分割线；列表与详情之间是分隔条。
  - **统计、设置**：沿用同样的头部、表面层级和排版规则（设置项在一张 raised 卡片上）。
- 分隔条：平时 1px 细线；悬停约 150ms 后变成 3px 陶土色线（变化本身 120），光标变成左右拖动；实际可抓取区域约 9px；
  双击恢复默认宽度；宽度记在本地。

## 6. 图标

- 只用 lucide 线性图标，16px 或 18px，线宽统一（`--icon-stroke`）。
- 界面中不出现任何 emoji；网格里的勾和叉用 SVG 画。
- 纯图标按钮必须有提示，内容是“名称 + 快捷键”（`IconButton` 强制 `label`，可选 `shortcut`）。

## 7. 组件（src/renderer/src/components/ui.tsx）

- **PageHead**：页面头部（eyebrow + 标题 + meta + 操作）。
- **Button**：主（陶土实色）、次（raised 底 + 1px 描边）、幽灵（平时无背景）；size：sm / md / lg（页面级主操作）。
- 悬停、按下、禁用、键盘聚焦四种状态在同类控件上一致；按下只变背景，不缩放、不位移；键盘聚焦有清晰聚焦环（`:focus-visible`）。
- **Tooltip**：floating-ui，碰撞检测；悬停 400ms 出现，移开立即消失；键盘聚焦时也显示。
- **Popover**：overlay 层；Esc 或点击外部关闭；打开时焦点进入，关闭后焦点回到触发处。
- **Dialog**：模态；焦点限制在框内；Esc 或关闭按钮关闭（点外部不关，防止丢失输入）。
- **EmptyState**：一个小图标加一句话。
- **Toast**：底部居中；可带“撤销”；5 秒后消失；同时最多 3 条。单词页输入行、义项面板、复习状态栏
  （data-toast-avoid）落在底部区域时，Toast 移到它们上方。
- **义项面板**（features/dict/SensePanel）：在词义框下方弹出，不抢焦点；义项是可切换的小块，选中用 `--tint-select`。
- **骨架屏**：静态浅色块，不做闪光扫描。

## 8. 动效（design-assets/motion/motion-spec.md）

原则：

1. **动效只用来说明刚刚发生了什么**，不做装饰；任何动效都不循环（唯一例外：AI 等待的荧光笔，第一个字出现即停）。
2. **品牌动效只用三笔**，和 Logo 一一对应：**划**（荧光笔扫过，scaleX，变换原点在左侧）、**写**（墨线写出，scaleX）、
   **勾**（沿笔画写出，stroke-dashoffset）。
3. **键盘高频操作不能等动画**：按键立即生效；动画可以被打断；新动画开始时先取消同一元素上正在播放的旧动画；连续快速按键时不能丢键。
4. 只对 transform 和 opacity 做动画；唯一的例外是小型 SVG 的 stroke-dashoffset（只重绘，不重排）。
5. 时长和缓动只能用 design.css 的动效变量：micro 120 / base 180 / panel 240（收起 170）/ sweep 200 / flash 600 / stagger 40，
   品牌动画总长 ≤ 800；另有 write 150、stroke 100、check 300。缓动：进入 `--ease-in`、退出 `--ease-out`、划写勾 `--ease-stroke`。
6. 工具在 `src/renderer/src/motion/`：`sweep` / `draw` / `fadeSlide`（Web Animations API，自动取消同一元素上的旧动画）、
   `useReducedMotion`、读取动效变量的 `duration` / `easing`。能用 CSS 实现的优先用 CSS。

| 场景                             | 动效                                                                                                                                                                             |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 冷启动开屏（≤800ms，任意键跳过） | 本子淡入 120 → 荧光笔划过 200 → 单词墨线写出 150 → 勾写出 200 → 开屏淡出、主界面淡入 130。与数据加载并行；数据未就绪则停在最终帧，超过 2 秒淡入“正在打开单词本”                  |
| 网格评分                         | 勾写出 200，随后到期高亮淡出 120；叉两笔各 100；模糊的淡色勾同写法；“漏”淡入 120；撤销时按写出的反方向收回 120                                                                   |
| Popover / 评分弹层               | 从锚点方向偏移 4px 淡入 180；关闭淡出 120                                                                                                                                        |
| 录入新词                         | 新行荧光笔划出 200 → 用 600 淡去；下方行 FLIP 下移 180；查重提示淡入 120                                                                                                         |
| 义项面板                         | 选中：荧光笔划过 200；取消：淡出 120；词义框文字即时更新，不做动画                                                                                                               |
| 复习卡片                         | 翻面：词义、音标、例句依次上浮 4px 淡入 180，间隔 40；换卡：旧卡左移 8px 淡出 120，新卡自右 8px 淡入 180；换卡中按评分键立即结束动画、直接显示下一张；“再来一次”提示用荧光笔划出 |
| 评分按钮                         | 键盘 1–4 选中：荧光笔划过 120；按下只变背景                                                                                                                                      |
| 进度条                           | 只用 scaleX，240，进入缓动，末端斜切，不回弹                                                                                                                                     |
| 完成页                           | 只写出 Logo 里的那一笔勾 300；下面的数字依次上浮淡入，间隔 40；不滚动、不撒花                                                                                                    |
| 切换页面                         | 内容区上浮 4px 淡入 120；导航选中底色用 transform 平滑滑到新位置 180                                                                                                             |
| 词库列表                         | 键盘移动选中项不做动画；详情淡入 120；删除行淡出 + 下方 FLIP 上移 180                                                                                                            |
| Toast                            | 自下 8px 淡入 180；淡出 120                                                                                                                                                      |
| Dialog                           | 遮罩淡入 180；对话框自下 8px 淡入 240                                                                                                                                            |
| 分隔条                           | 悬停 150ms 后开始变化，变化本身 120                                                                                                                                              |
| 统计页（尚未实现）               | 数字依次上浮淡入 180，间隔 40；图表只做一次 scaleY 入场 240，不循环                                                                                                              |

**减少动态效果**：去掉所有位移，只保留 120ms 以内的淡入淡出；划、写、勾直接显示最终状态；开屏只显示静态 Logo，数据就绪立即进入。
（design.css 在 `prefers-reduced-motion: reduce` 时把位移变量归零、时长缩短或归零；motion 工具同样判断。）

## 9. 交互原则

- 按需出现：工具默认隐藏（例如行尾的难词、删除按钮只在悬停或聚焦时出现）。
- 不遮挡：状态栏、面板都是占位式的，把内容挤开，而不是浮在内容上面。
- 键盘优先：常用操作都有快捷键；焦点在输入框里时全局快捷键不触发。
- 可撤销：删除一律软删除，并弹出可撤销的 Toast；评分也可以撤销。
- 记住用户的选择：主题、上次打开的页面、复习方向、栏宽等。

## 10. 品牌

- **XWordMark**（design-assets/logo/xword-mark.svg）：一本带三个线圈的单词本；纸面上一道荧光笔（下）和一道单词墨线（上），
  右侧一条复习栏竖线和一个勾。viewBox 100×100。颜色全部用变量：纸面 `--paper`，描边和线圈 `--ink`，复习栏竖线 `--rule-strong`，
  荧光笔 `--marker`，单词墨线 `--mark-word`（浅色主题 = `--ink`，深色主题 = `--paper`），勾 `--ink`。
- 组件属性：`size`；`variant`：default / mono（xword-mark-mono.svg：荧光笔、竖线为墨色，单词墨线为纸色）；
  `small`：size ≤ 32 时自动开启，换成加粗描边的 xword-mark-small.svg 几何；`animate`：splash（开屏三笔）/ check（只写出勾）。
- 使用位置：开屏、侧栏顶部（28px 图形 + 22px 衬线字标）、复习页左上角、完成页。
- **字标**：“XWord”，衬线字体，字重 600，字距 -0.02em。
- **应用图标（D1）**：直接使用 design-assets/icon/app-icon.ico（npm run icon 原样复制成 build/icon.ico，16/24/32/48/64/128/256，
  16 和 24 是专门绘制的两线圈版本，不重新生成）。exe、安装程序、卸载程序（installerIcon / uninstallerIcon / installerHeaderIcon）、
  桌面和开始菜单快捷方式（用 exe 内嵌图标）、窗口左上角和任务栏（BrowserWindow 显式设 icon；AppUserModelId com.sean.xword）都是它。

## 11. 复习流程

1. 概览：到期复习几个、新词几个、其中拖欠几个；预计用时（每词 8 秒，取整到分钟）；队列可逐项跳过；
   方向切换“英 → 中 / 中 → 英”（记在本地）；“开始复习”（Enter）。
2. 卡片正面只显示单词（衬线大字），上方小字“第 N 页 · 节点标签”，难词带 Star；空格翻面显示音标、词义、例句、助记。
3. 翻面后卡片下方固定位置出现 4 档评分：忘了 / 模糊 / 记得 / 很熟。1–4 选中（可改选），Enter 确认；鼠标点击直接确认。
   确认后立即换到下一张，写库在后台按顺序排队，快速连按不丢键。
4. 底部状态栏：荧光笔进度条、“3 / 8”（只算第一次作答）、“跳过”（S）、“结束”（Esc）。
5. Ctrl+Z 撤销上一次第一次作答并回到那张卡片；重现卡片上方显示“再来一次”。
6. 完成页：今天复习了几个、其中忘了几个、明天待复习几个；Logo 里的那一笔勾写出一次。不撒花，不做数字滚动。

## 12. 阅读器（v0.3）

- **侧栏**：最上方“今日”；分组「阅读」书架、高亮与笔记；「单词」今日复习、单词本、词库；底部连续打卡、统计、设置。分组标题 12px 次要色。Ctrl+1–8 按侧栏顺序。
- **今日首页**：两张 raised 卡片——继续阅读（生成封面、书名、当前章节、荧光笔进度条、“继续”）与今日复习（衬线 60px 数字、“开始复习”）；
  下方“今天从书里收的词”（单词衬线、词义次要色、右侧《书名》）。两个按钮只有一个是陶土色：有待复习时是“开始复习”，否则是“继续”。
- **书架**：「我的书 / 发现」分段切换；封面由软件生成（纸色底、衬线书名、斜体作者、底部荧光笔色块、末端斜切），网格 136×192；
  移除按钮悬停时出现；把文件拖进窗口时整窗出现虚线提示。发现页一行一本：衬线书名、作者、下载次数（衬线数字）、下载 / 进度 / 打开。
- **阅读页**：v0.4 起改为一页一页的书页，见第 13 节「书页排版」。
- **标记**：单词本里的词 = `--meet-line` 虚线下划线，今天到期 = `--marker` 更粗；熟词不标。高亮底色 `--hl-*`（黄 重点 / 绿 已懂 / 红 疑问 / 蓝 待查 / 紫 灵感，
  一律 color-mix 半透明）。选中文字的底色 `--tint-select`。
- **浮层**：查词卡片 360px（单词衬线 26px、音标、原形提示、分组义项、考试标签、“收进单词本 A”主按钮、我认识、发音）；
  选区工具条（翻译、五个色点、笔记、收词、复制）；高亮菜单（色点、笔记、查词、删除）；翻译面板 440px；目录抽屉从左滑出（只动 transform）。
- **动效**：收词后荧光笔下划线划出 200ms 再淡去；新建高亮荧光笔从左往右划出 200ms（多行依次）；跳转到出处 / 高亮后选中色标出再淡去；
  AI 等待是全软件唯一的循环动效（`--dur-ai-wait`，第一个字出现即停，减少动态效果时为静止淡色）。
- **复习卡片出处**：翻面后显示最近一条出处的句子（衬线，目标词 `--tint-select` 底色），下方 12px 小字“《书名》第 N 章”，点击跳回原文。
- **设置 · AI 翻译**：key 输入框遮盖显示，“保存”是设置页唯一的陶土色按钮；状态点：已设置 = 荧光笔色，未设置 = 淡色。

## 13. 书页排版（v0.4）

所有数值都来自 design.css 的变量（`--page-*`、`--spine-*`、`--book-*`、`--chapter-*`、`--toc-*` 等）。

- **版面**：窗口背景是 `--desk`；书页是抬起的纸（`--paper`、`--shadow-2`、圆角 `--page-radius` 4px）。双页时中缝两侧各有 16px 渐变阴影，
  不透明度不超过 0.06（`--spine-shade`）。顶栏 48px、底栏 40px 用纸面，和书页区之间用 `--hair` 细线分隔；图标一律 lucide 18px，
  纯图标按钮有带快捷键的 Tooltip（返回 Esc、目录 M、页面设置 P）。
- **书页尺寸**：高 = 可用高度 − 上下各 24px；宽 = 高 × 0.68，但不超过可用宽度（双页时一半）。页边距三档：窄 40/48、中 56/64、宽 72/80（左右 / 上下），默认中。
  窗口宽度 ≥ 1100px 时默认双页，每章第一页单独在右侧（左边空白页）；窄窗口单页。空白页不编号。
- **正文**：`--font-serif`，默认 19px，行高 1.6，两端对齐，`hyphens: auto`（lang = en）。段落之间不空行；标题、分隔线、图片、表格之后的第一段不缩进，
  其余首行缩进 1.5em。孤行、寡行至少 2 行；标题不与下一段分开；图片不跨页。引文左右各缩进 2em、字号 0.95 倍；列表每级缩进 1.5em（序号、圆点用伪元素）。
- **标题分级**：章首另起一页，页面上方留出 1/3 空白；标签（如 CHAPTER 3）12px 小型大写、字距 0.12em、次要色；章名 32px、字重 500、字距 0.01em，
  与标签相距 12px，章名下方留 2.4em。二级标题 22px / 600，上 2.2em 下 0.8em；三级 18px 斜体 / 500，上 1.8em 下 0.6em；四级及以下与正文同字号、加粗、上 1.4em。
- **页眉页脚**：页眉 11px 小型大写、`--soft`（= `--ink-2`）色；左页书名、右页章名（单页时章名居中）；章首页不显示页眉。页脚页码在外侧，衬线等宽数字，`--faint`。
- **底栏**：“第 N 页”（总页数在后台算好后变为“第 N / M 页”，点一下可输入页码跳转）、荧光笔样式的细进度线（末端斜切）、本章剩余页数、全书百分比。
- **目录抽屉**：从左侧滑出（只动 transform），宽 320px，overlay 表面；按“前言部分 / 正文 / 附录”分组，组名 12px `--faint`；每深一级缩进 16px；
  一级 14.5px / 600，二级 14px，三级及以下 13px `--soft`；页码右对齐、衬线等宽数字、`--faint`；当前章节用 `--tint-select` 底色。
- **浮层**：查词卡片、选区工具条、翻译面板、页面设置、目录抽屉都用 overlay 表面、`--shadow-3`、圆角 14、内边距 16–18px，标题 15px / 600；
  按钮沿用全局规范，出现和消失按动效规范。选区工具条是一行图标按钮，内边距取按钮自身的点击区（见 DECISIONS）。
- **高亮**：黄 / 绿 / 红 / 蓝 / 紫五色都是 design.css 里 color-mix 的半透明色，文字保持清晰；PDF 上的高亮画在覆盖层里，同样半透明。
- **翻页动效**：新的一屏从翻页方向淡入，位移 12px，180ms；减少动态效果时直接切换；快速连按直接跳到目标页，不排队、不丢键。
- **PDF 原版页面**：页面和印刷版一样（画布 + 透明文字层），深色主题下纸张保持原色（`--pdf-paper`）；缩放：适合宽度 / 适合页面 / 75%–200%，默认适合页面。
- **原书版式 / 统一版式**：原书版式使用原书 CSS 白名单映射出的样式（对齐、缩进、字形、小型大写、大小写、上下外边距 0–3em、分页），统一版式只按本节规范；
  两种都遵守上面的排版规则。
