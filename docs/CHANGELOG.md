# 更新记录

## 0.4.1（2026-10-05）

- 增加全软件单词朗读：阅读查词、词典义项与原形、单词本、录入行、批量预览、词库列表/详情/熟词、今日队列和首页收词都有扬声器按钮。
- 复习默认自动朗读，可在概览和复习中关闭并记住选择；英译中显示英文时朗读，中译英翻面后才朗读。复习、单词本网格和词库详情支持 R 重播。
- 使用 Windows 已安装的本地英语语音，优先美式英语，无需联网或 API key；没有可用语音时给出中文提示。快速重播、换词和退出会取消旧声音。
- 保持现有页面结构、复习规则和数据库版本 8，不增加依赖。义项面板尺寸改变后的定位延后到下一帧，避免布局观察回调重复更新。

## 0.4.0（2026-09-24）

阅读页改成像真正的书一样一页一页地读。

### 书页排版（EPUB / TXT）

- 书页是桌面上的纸：宽窗口默认双页（每章第一页在右页），窄窗口单页；页眉（左页书名、右页章名）、页码在外侧；章首另起一页、上方留白，标签和章名分开排版。
- 正文衬线 19px、行高 1.6、两端对齐、段首缩进；标题、引文、列表、表格、图片和图片说明都按原书结构排出来；孤行寡行、标题不与下一段分开、图片不跨页。
- 翻页：← / → / PageUp / PageDown / 空格、点击左右两侧、滚轮一格一页、Home / End 到本章首尾；快速连按直接跳到目标页。
- 底栏：第 N / M 页（点一下输入页码跳转）、荧光笔进度线、本章剩余页数、全书百分比。目录抽屉按“前言部分 / 正文 / 附录”分组、按层级缩进，带页码。
- 页面设置按书记住：字号 16–24、行高 1.4–1.9、页边距窄 / 中 / 宽、单页 / 双页、原书版式 / 统一版式。
- 阅读位置、高亮、出处都记在文字上（不记页码）：改字号、窗口大小、单双页后，刚才读的内容还在当前页。

### EPUB 解析（修复）

- 修复标题首字母被拆开（“F OREWORD”）：放大的首字母和后面的字母之间的换行被当成了空格，现在合并回一个词。
- 修复书自带的目录页挤成一团：只靠样式分行的目录项被合成了一段，现在每项单独一行，并按目录层级重新排成嵌套列表。
- 保留原书结构（标题级别、嵌套列表、表格、图片、小型大写、上下标、书内链接），原书样式只取安全的几项（对齐、缩进、字形、间距、分页）。
- 旧书第一次打开时自动按新规则重新解析，阅读位置、高亮和出处自动换算；v0.3 导入的书没有保存原文件，需要重新导入一次同一个文件。
- 前言等前置内容超过 10 页时，第一次打开显示“跳到正文”。TXT 的 BOOK / PART 是一级标题，CHAPTER 是二级标题。

### PDF

- 可以直接导入 PDF：页面和印刷版完全一样，文字可以选中；查词、收词、高亮、笔记、翻译都能用，行尾用连字符断开的单词也能查到完整的词。
- 缩放：适合宽度 / 适合页面 / 75%–200%，按书记住；深色主题下纸张保持原色；书签就是目录。
- 扫描版 PDF（页面是图片）给出说明，暂不支持。

## 0.3.0（2026-09-24）

XWord 升级为“英文原著阅读器 + 艾宾浩斯单词本”：读 → 收 → 背 → 再读时遇见。

### 时间（修复）

- 修复“早上打开仍显示前一天、新词写进前一天那一页”：原因是界面只在窗口获得焦点时刷新，电脑睡眠跨过午夜后窗口一直有焦点，“今天”停在前一天。
- 所有日期改为跟随电脑系统的本地时区和本地时间（改了系统时区，软件也跟着改）。“今天”每次实时计算；系统唤醒、屏幕解锁、
  窗口获得焦点、页面重新可见、每 60 秒各检查一次，日期或时区变了立即刷新今日队列、导航数量、单词页和首页。
- 首次启动时按本地时区重新换算已有的复习日期、第1遍日期和页的开始日期（换算前自动备份，日志里记录改动条数）。

### 图标

- exe、安装程序、卸载程序、桌面和开始菜单快捷方式、窗口左上角和任务栏全部换成 D1 图标（与设计稿的 ico 完全一致）；开发模式也不再显示 Electron 默认图标。

### 阅读器

- 侧栏改为两组：「阅读」书架、高亮与笔记；「单词」今日复习、单词本、词库；最上方是新的“今日”首页（继续阅读、今日复习、今天从书里收的词），冷启动进入首页。
- 书架：「我的书」统一生成的封面和阅读进度，导入按钮或把文件拖进窗口即可导入；「发现」搜索 Project Gutenberg 的英文书（默认最热门的 32 本）并一键下载，
  底部可去 Standard Ebooks、Project Gutenberg 官网挑书。
- 导入 EPUB 2 / 3 和 TXT（UTF-8 / UTF-16 / Windows-1252），全部转成统一格式：所有书看起来都一样、没有乱码；Gutenberg 的前后说明自动去掉。
  PDF 提示先用 Calibre 转成 EPUB；带 DRM 的书给出说明；同一本书不会重复导入。
- 阅读页：细栏 + 荧光笔进度线，正文单栏居中排在纸面上；Aa 调字号、行高、版心宽度；目录抽屉；上一章 / 下一章；
  记住读到的位置（改字号也不跑）；超长章节窗口化渲染；快捷键 ↑ ↓ 空格 [ ] Esc T H A。
- 点单词查词（音标、原形、义项、考试标签），一键收进单词本（写进今天的页，已有的词只追加出处）；复习卡片翻面后显示出处句子，点一下跳回书里；
  词库详情新增“出处”。单词本里的词在书里出现时有淡淡的荧光笔虚线（今天到期的更明显）；“我认识”的词和它的变形不再标记，可在词库里撤销。
- 高亮与笔记：选中文字后的工具条（翻译、五色高亮、笔记、收词、复制），高亮可撤销；新的「高亮与笔记」页按书分组，点击跳回原文。
- 连续打卡：当天有过一次复习作答，或者累计阅读满 5 分钟都算。

### AI 翻译

- 设置页新增“AI 翻译”：填写 DeepSeek API key（加密保存，不回传界面）、测试连接、清除、模型名称。
- 阅读时选中句子按 T：选区下方显示流式译文；「解释这句」讲解句子结构、难点词和语气；同一段文字再次翻译直接读缓存。
  没有 key、key 无效、余额不足、请求太频繁、断网、超时都有中文提示，可以重试；翻译失败不影响阅读。

### 数据

- 数据库升级到版本 7：本地时间换算、书目与阅读时长、出处、熟词、高亮与笔记、翻译缓存。书的正文保存在数据文件夹的 books 目录（不参与每日备份）。

## 0.2.1（2026-09-24）

### 时间

- 全软件的业务时区统一为北京时间（Asia/Shanghai），与电脑的系统时区无关：“今天”、复习日期、到期 / 拖欠、新词上限、每日备份、
  跨午夜刷新和界面上的日期时间都按北京时间 00:00 分界。
- 首次启动时自动按北京时间校正旧数据里的日期（检查格日期、第1遍日期、页的开始日期），校正前单独备份数据库。

### 品牌

- 新 Logo：一本带线圈的单词本（荧光笔、单词墨线、复习栏竖线和一个勾）；新的应用图标（16 / 24px 为专门绘制的小尺寸版本）。
- 冷启动开屏：本子淡入 → 荧光笔划过 → 单词写出 → 勾写出，约 0.8 秒，按任意键跳过，不拖慢打开速度。

### 界面 v2

- 四层表面：桌面、纸面、抬起、浮层，靠明度分层；侧栏 232px（Logo、导航、连续打卡、设置）。
- 页面头部统一为“小标题 + 标题 + 说明 + 操作”；统计数字、进度、日期用衬线字体。
- 单词页：行高 46、复习栏竖线、两行表头（今天用陶土色标出）、底部图例；今日复习：三组大数字和复习顺序卡片；
  复习中：居中大卡片、四个大评分按钮、底部状态栏；词库：页头搜索、胶囊筛选、分区只靠留白的详情。
- 侧栏新增“连续打卡”天数。

### 动效

- 网格评分时勾 / 叉沿笔画写出，撤销时收回；录入新词时新行被荧光笔划出；义项和评分按钮选中时荧光笔划过。
- 复习卡片翻面时内容依次浮现，换卡左出右进；复习时按键立即生效，快速连按不丢键。
- 页面切换、导航、弹层、Toast、对话框、词库删除都有简短的过渡；系统开启“减少动态效果”时只保留短暂的淡入淡出。

## 0.2.0（2026-09-23）

### 新功能

- **录入时从词典选词义**：单词框按 Enter 后，词义框下方弹出义项面板，显示音标、考试标签（中考 / 高考 / 四级 / 六级 / 考研 / 托福 / 雅思 / GRE）、牛津核心词，
  以及屈折形式提示（如“went 是 go 的过去式”，可一键“改录 go”）。义项按词性分组，点选或按 1–9 切换，词义框里实时生成
  “n. 能力；才能 adj. 有能力的”这样的文字；手动改过后可“按所选重新生成”。查不到的词照常手动输入。
- 单词新增**音标**，从词典自动带入；复习卡片翻面后在单词下方显示音标。
- **批量录入**：没写词义的行自动填入词典的第一组义项（标注“来自词典”），写入前可以修改。
- **词库页**：列表 + 详情两栏，分隔条可拖动、双击复原；搜索（Ctrl+F）、九个筛选（全部 / 今日到期 / 拖欠 / 难词 / 新词 /
  学习中 / 已掌握 / 需要重学 / 回收站）、四种排序；3000 个词也流畅。详情里可以编辑单词、音标、词义、例句、助记，
  查看 6 个节点和复习历史，跳到单词页对应的行，标记难词、删除、恢复、彻底删除、清空回收站，也可以从词典选择词义。
- 内置 ECDICT 精简词典（67 万词条，完全离线）；设置页注明“词典数据：ECDICT（MIT License）”，许可证随安装包分发。

### 改进与修正

- Toast 不再遮挡单词页的输入行、义项面板和复习页的状态栏。
- 没有词义时第一次按 Enter 只提示，再按一次才写入。
- 安装程序固定为“当前用户”安装，不再出现“仅为我 / 所有用户”选择页。
- 安全：打包版忽略开发和测试用的开关（数据目录、远程调试端口等）；开启 Electron fuses（禁止当作 Node 运行、
  忽略 NODE_OPTIONS 和 --inspect、只从 app.asar 加载并校验完整性）。

### 数据

- 数据库表结构升级到版本 2（words 增加 phonetic）；首次启动时自动迁移，迁移前的数据库已由每日备份保存。
