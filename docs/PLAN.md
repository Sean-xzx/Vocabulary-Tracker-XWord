# XWord 单词朗读功能计划

## 当前任务（2026-10-05）

目标：所有独立查看单词的位置都可手动听英语发音，复习可自动朗读。保持现有页面、业务规则、IPC、数据库和依赖结构。

1. 复用浏览器系统 TTS，提取共用朗读服务和按钮；旧阅读 speech 入口保留兼容。只选本地英语语音，处理异步语音加载、错误与连续播放的取消，不增加网络请求/依赖。
2. 接入阅读查词、词典义项、复习、复习队列、单词本、录入、批量预览、词库列表/详情/熟词、首页收词。按钮用现有图标与提示，避免嵌套按钮，保留表格键盘行为。
3. 复习默认自动朗读英文，提供记住选择的开关与 R 重播；中译英仅翻面后朗读。换词、跳过、撤销和退出取消旧播放；不动评分、日期、队列及持久化语义。
4. 验证语音服务的延迟加载/取消/错误，真实窗口用 mock 语音检查各入口和复习不泄题、不影响评分；运行 typecheck、test、lint、构建及完整 E2E，检查浅深视觉。
5. 更新进度、变更与上下文资料，按项目约定本地提交，不 push。自动测试不证明扬声器实际声音，需单独标明真人试听范围。

验收（2026-10-05）：以上实现完成；typecheck、213 个单元测试、lint（无错误）、构建和 72 项 E2E 通过，浅深截图自查。额外在真实本地英语引擎完成 ability 播放的 start/end 检查；真人听感留给用户试听。版本更新为 0.4.1，安装包、进度与上下文资料同步交付。

## 一 安全与依赖（写进 CLAUDE.md）

联网只在主进程、只限 gutendex.com / www.gutenberg.org（含 gutenberg.org 下载跳转）/ api.deepseek.com，请求一律超时；
openExternal 只开 https 白名单；导入的书按不可信内容处理（只取文本结构、200MB / 解压 500MB / 条目数上限）；
新增 fflate；key 用 safeStorage；测试开关只在未打包时有效。

## 二 时间：跟随本地系统时间

dates.ts 去掉固定北京时间，函数接收 now / instant + 可选 timeZone（默认系统当前时区）；渲染进程每次 IPC 附带当前时区，
主进程校验后使用；日期检查（resume / unlock-screen / focus / visibilitychange / 60 秒）变了就刷新；迁移 4 按本地时区重算；
lint 规则；根因回归测试；四种时区边界测试。
