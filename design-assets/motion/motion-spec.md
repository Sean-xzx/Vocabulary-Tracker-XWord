# XWord 动效规范

## 原则
1. 动效只说明“刚刚发生了什么”，不做装饰。
2. 品牌动效只由三笔组成，和 Logo 一一对应：**划**（荧光笔从左往右扫过，scaleX）、**写**（墨线写出，scaleX）、**勾**（沿笔画写出，stroke-dashoffset）。
3. 键盘高频操作不等动画：按键立即生效，动画可随时被打断，新动画开始时取消同一元素上的旧动画；绝不丢键、绝不延迟下一步。
4. 只对 transform 和 opacity 做动画；唯一例外是小型 SVG 的 stroke-dashoffset（只重绘，不重排）。

## 变量
见 `motion-tokens.css`：micro 120 / base 180 / panel 240（收起 170）/ sweep 200 / flash 600 / stagger 40，品牌动画总长 ≤ 800ms。
缓动：进入 `cubic-bezier(.2,0,0,1)`；退出 `cubic-bezier(.4,0,1,1)`；划写勾 `cubic-bezier(.65,0,.35,1)`。

## 逐项
| 场景 | 动效 |
|---|---|
| 冷启动开屏（≤800ms，任意键跳过） | 本子淡入 120 → 荧光笔划过 200 → 单词墨线写出 150 → 勾写出 200 → 开屏淡出、主界面淡入 130。与数据加载并行；数据未就绪则停在最终帧，超 2 秒淡入“正在打开单词本” |
| 网格评分 | 勾写出 200，随后到期高亮淡出 120；叉两笔各 100；模糊的淡色勾同写法；“漏”淡入 120；撤销时反向写回 120 |
| Popover / 评分弹层 | 从锚点方向偏移 4px 淡入 180；关闭淡出 120 |
| 录入新词 | 新行荧光笔划出 200 → 用 600 淡去；下方行 FLIP 下移 180；查重提示淡入 120 |
| 义项面板 | 选中：荧光笔划过 200；取消：淡出 120；词义框文字即时更新 |
| 复习卡片 | 翻面：词义、音标、例句依次上浮 4px 淡入 180，间隔 40；换卡：旧卡左移 8px 淡出 120，新卡自右 8px 淡入 180；换卡中按评分键立即结束动画；“再来一次”提示用荧光笔划出 |
| 评分按钮 | 键盘 1–4 选中：荧光笔划过 120；按下只变背景 |
| 进度条 | scaleX 240，进入缓动，末端斜切，不回弹 |
| 完成页 | 只写出 Logo 的那一笔勾 300；三组数字依次上浮淡入，间隔 40；不滚动、不撒花 |
| 切换页面 | 内容区自下 4px 上浮淡入 120；导航选中底色用 transform 滑到新位置 180 |
| 词库列表 | 键盘移动选中项不做动画；详情交叉淡入淡出 120；删除行淡出 + 下方 FLIP 上移 180 |
| Toast | 自下 8px 淡入 180；淡出 120 |
| Dialog | 遮罩淡入 180；对话框自下 8px 淡入 240 |
| 分隔条 | 悬停 150ms 后开始变化，变化本身 120 |

## 减少动态效果
去掉所有位移，只保留 ≤120ms 的淡入淡出；划、写、勾直接显示最终状态；开屏只显示静态 Logo，数据就绪立即进入。

## 预览
`motion-preview.html`（浏览器打开，循环播放）和 `motion-preview.webm`（录屏）。预览为了展示而循环，软件里任何动效都不循环。
