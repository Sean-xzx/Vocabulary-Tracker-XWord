# XWord 设计资源包

解压到 XWord 项目根目录，文件夹名保持为 `design-assets`。

- `logo/` 标志：图形（浅色 / 深色 / 单色 / 小尺寸加粗版）、横排字标 SVG（字标依赖 Newsreader 或 Georgia 字体）、1024px PNG。
- `icon/` 应用图标：`app-icon.svg`（≥48px）、`app-icon-small.svg`（32px）、`app-icon-tiny.svg`（16–24px 专用，两个线圈、无单词墨线）、`app-icon-dark.svg`、`app-icon.ico`（内含 16/24/32/48/64/128/256，小尺寸为专门绘制的版本）、`png/` 各尺寸。
- `motion/` 动效：`motion-spec.md` 规范、`motion-tokens.css` 变量、`motion-preview.html` 可循环预览、`motion-preview.webm` 录屏。
- `ui/` 界面：`ui-spec-v2.md` 规范、`design-tokens.css` 变量、`ui-*.html` 四张参考稿（单词页、今日复习、复习中、词库深色）、`preview/*.png` 截图（本机渲染，衬线字体为近似替代）。

颜色：墨色 #2B2622、纸色 #FAF7F2、桌面 #F3ECE1、荧光黄 #D9B23A、陶土 #C9814B。
