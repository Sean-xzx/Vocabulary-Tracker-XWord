# XWord 界面规范 v2：简约、大气、有层次

颜色沿用原方案，变化集中在“层次”和“留白”。参考稿见同目录 `ui-*.html`（浏览器打开）与 `preview/*.png`（本机渲染，字体为近似替代）。

## 1. 四层表面（层次感的来源）
从低到高：**desk 桌面 → paper 纸面 → raised 抬起 → overlay 浮层**。每升一层：颜色更亮一点、阴影更重一级。
- desk：窗口底色，侧栏直接放在桌面上，不画边框。
- paper：主内容区是一张“纸”，距窗口上、右、下各 12px，圆角 18，`--shadow-1`。
- raised：纸上的卡片、列表、输入框、选中项、复习卡片。
- overlay：Popover、菜单、Dialog，`--shadow-3`。
- 同一层之间不用边框区分，用上下层的明度差区分；1px 线只用于表格行（`--hair`）和控件描边（`--line`）。

## 2. 排版
| 用途 | 规格 |
|---|---|
| 页面标题 | 界面字体 26px / 600，上方 13px 次要色小标题（eyebrow） |
| 统计大数字 | 衬线 60px / 500，tabular-nums |
| 复习卡片单词 | 衬线 60px / 600，字距 -0.02em |
| 词库详情单词 | 衬线 40px / 600 |
| 网格单词 | 衬线 18px / 400 |
| 正文、词义 | 14.5–15px；网格词义用次要色 |
| 标签、表头 | 12–13px，次要色 |
| 快捷键提示 kbd | 11px，raised 底，1px 描边，圆角 5 |
所有数字（进度、统计、日期）用衬线字体 + tabular-nums。中文一律用界面字体。

## 3. 布局与间距
- 间距阶梯：4 / 8 / 12 / 16 / 24 / 32 / 44。页面内边距：上 32，左右 44。
- 侧栏 232px：顶部 Logo + 字标（28px 图形 + 22px 衬线），导航项高 38、圆角 10、图标 18；选中项 = paper（深色用 raised）底 + `--shadow-1` + 字重 600；“今日复习”右侧数量胶囊用 `--tint-select`。侧栏底部：连续打卡小卡片 + 设置。
- 页面头部：左边 eyebrow + 标题 + 一行 meta；右边操作按钮。每屏最多一个主按钮。
- 按钮：高 36、圆角 9；页面级主操作（开始复习）高 48、圆角 12、带 kbd 提示。
- 圆角阶梯：5 / 9 / 10 / 14 / 18 / 22。

## 4. 各页面
- **单词页**：表格直接画在纸面上，行高 46，行间 `--hair`；“词义”与复习栏之间一条 1.5px `--rule-strong` 竖线（呼应 Logo）；复习列宽 64，表头两行（节点名 + 衬线日期），今天那一列表头用陶土色写“今天”；到期格 `--tint-due`、拖欠格 `--tint-late` + 右上角陶土色小点；输入行用 raised 底；义项面板是 overlay。
- **今日复习概览**：三组衬线大数字（到期复习 / 新词 / 其中拖欠），用细竖线分隔；右侧“预计 N 分钟” + 主按钮；下方 raised 列表显示复习顺序，后几行渐隐。
- **复习中**：侧栏收起，整个窗口是桌面；中央卡片 640×400、raised、圆角 22、`--shadow-2`；卡片下方四个评分按钮 138×52，选中用 `--tint-select`；底部 56px 状态栏（paper 底 + 顶部 hair 线）：荧光笔进度条、衬线“8 / 28”、跳过、结束。
- **词库**：列表 + 详情；列表行高 56（单词 + 一行词义），选中行 raised + `--shadow-1`；筛选用胶囊按钮；详情按“词义 / 助记 / 例句 / 复习格 / 复习历史”分区，分区之间靠留白而不是分割线。

## 5. 克制原则
- 每屏只允许一个陶土色主元素（主按钮或“今天”标记）。
- 黄色只用于三件事：荧光笔（Logo、进度条）、到期/选中的半透明底、难词星标。
- 不用渐变、不用彩色大阴影、不用 emoji；留白是有意的，不要为了“填满”加东西。
